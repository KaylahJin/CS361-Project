# #139 ล็อกอินจากหน้าแผนสหกิจแล้วเจอหน้าลงชื่อซ้ำ

ถ่ายจากเว็บจริงด้วย Chrome: เปิดเว็บตอนยังไม่ล็อกอิน เข้าแท็บ "แผนสหกิจ" กรอกฟอร์มล็อกอินของหน้านั้นด้วย student1 แล้วกดเข้าสู่ระบบ

| | หลังล็อกอิน | API ที่หน้าเว็บเรียก |
|---|---|---|
| ก่อนแก้ | หัวหน้าเว็บขึ้นว่าล็อกอินแล้ว แต่ตัวหน้ายังขึ้น "ลงชื่อเข้าใช้เพื่อดูแผนสหกิจ" และไม่โหลดแผน (`139-02`, `139-03`) | `GET /coop-plans` ได้ `401` ครั้งเดียว |
| หลังแก้ | เห็นรายการแผนทันที (`139-04`, `139-05`) | `GET /coop-plans` ได้ `200` |

สาเหตุ: `getIdToken` อ่าน `statusRef` ซึ่งอัปเดตใน effect หน้าแผนที่เพิ่ง mount เพราะสถานะเปลี่ยนเป็นล็อกอินแล้ว รัน effect ของตัวเองก่อน effect ของ provider จึงเรียก API โดยไม่มี token
