# #224 [V5-03] Repeatable deployment — local dry run (2026-11-09)
#
# What this is: the three deploy scripts run end to end on Windows/Git Bash
# with `terraform` and `aws` replaced by stubs on PATH (this machine has
# neither, nor the team's Terraform state). The stubs return fixed
# `terraform output` values and log every `aws` call; a local Node server
# on 127.0.0.1:8787 stands in for API Gateway and the S3 website.
#
# What it proves: dependency install, packaging inputs, the order of steps,
# which Terraform outputs reach the build, the post-deploy checks (pass AND
# fail), and that every script can be re-run without changing anything.
# What it does NOT prove: a real deploy on AWS — that evidence is added to
# the issue separately, from a machine holding the Terraform state.
