# #142 ผู้ตรวจดูประวัติและหน้าตรวจไม่มีบั๊ก

ถ่ายจากเว็บจริงด้วย Chrome ล็อกอิน staff1 เปิดแผน #10 (นักศึกษา 6600000002) ซึ่งเป็น `SUBMITTED` จากหน้ารายการ แล้วตรวจ 2 รอบ

| รอบ | สิ่งที่ทำ | ผล |
|---|---|---|
| 1 | เปิดแผนด้วยการคลิกแถว กดปุ่ม "ตรวจพิจารณาแผน" ในหน้ารายละเอียด เลือก "ส่งกลับให้แก้ไข" ใส่เหตุผล บันทึก | หน้าต่างตรวจเปิดขึ้น ช่องความเห็นว่าง บันทึกได้ (`POST /review` 200) ประวัติขึ้น 1 รายการ |
| 2 | ตั้งแผนกลับเป็น `SUBMITTED` (`docs/evidence/scripts/142-set-plan-status.sql`) แล้วตรวจอีกรอบ เลือก "อนุมัติ" | ช่องความเห็นว่างทั้งที่รอบ 1 มีความเห็น (F12) ประวัติขึ้น 2 รายการ รอบล่าสุดอยู่บนสุด รอบแรกยังอ่านเหตุผลได้ |

หลังถ่ายคืนแผน #10 กลับเป็นเดิมด้วย `142-reset-plan.sql` (ลบแถว `plan_reviews` ของแผน คืนสถานะ `SUBMITTED` ไม่มีผลพิจารณา)

## บั๊กที่พบระหว่างทำหลักฐาน
ปุ่ม "ตรวจพิจารณาแผน" ในหน้ารายละเอียดไม่ทำอะไรเลย (F11 ยังเกิดอยู่จริง) เพราะหน้าต่างตรวจถูก render เฉพาะใต้หน้ารายการ ส่วนหน้ารายละเอียดคืนค่าไปก่อน จึงไม่มีหน้าต่างให้เปิด แก้โดยสร้างหน้าต่างตรวจครั้งเดียวและ render ทั้ง 2 หน้า และหลังบันทึกจากหน้ารายละเอียดจะโหลดแผนใหม่เพื่อแสดงผลและประวัติล่าสุด test ใหม่ 2 ข้อ fail เมื่อถอนการแก้ และผ่านเมื่อมีการแก้

## F20 และตัวกรองสถานะ
ตัวกรองนับ `PREPARING` ("ฉบับร่าง") อยู่แล้ว ดูภาพรายการของทุก role ใน `141-03-*-plans.png` สถานะใหม่ (`ENDORSED`, `ELIGIBLE` ฯลฯ) มาจาก #147 (P4.1) ข้อนี้จึงรอ #147

## ทำซ้ำได้อย่างไร
สคริปต์อยู่ในโปรเจกต์ `docs/evidence/scripts/142-capture-review-history.mjs` (วิธีใช้อยู่ในหัวไฟล์) สคริปต์นี้บันทึกผลตรวจจริง ใช้กับ DB ของ lab แล้วคืนค่าด้วย `142-reset-plan.sql`

```bash
npm i --no-save playwright-core
EVIDENCE_SITE_URL=http://<bucket>.s3-website-us-east-1.amazonaws.com COOP_TEST_PASSWORD=... \
  node docs/evidence/scripts/142-capture-review-history.mjs 142-01-round1 6600000002 RETURNED "กรุณาแนบ Transcript ฉบับล่าสุด"
psql ... -v plan=10 -v status=SUBMITTED -f docs/evidence/scripts/142-set-plan-status.sql
node docs/evidence/scripts/142-capture-review-history.mjs 142-02-round2 6600000002 APPROVED ""
psql ... -v plan=10 -f docs/evidence/scripts/142-reset-plan.sql
```
